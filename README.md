# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies required.

## Customize it first

1. Open `index.html`.
2. Replace **Your Name**, `yourname`, and **Your City, Country** with your details.
3. Update the About section to describe your background.
4. Replace the example projects and their GitHub links with your real projects.
5. Replace `hello@example.com` with your email address.
6. Update the GitHub and LinkedIn profile links near the bottom.
7. Adjust the skills to match your experience.

## Preview locally

Open `index.html` in your browser. For a local development server, use the VS Code Live Server extension.

## Publish to GitHub

1. Create a new **public** repository on https://github.com/new, for example `my-portfolio`. Leave the README initialization unchecked if you plan to push this folder as-is.
2. Unzip this project and open a terminal in the `portfolio-website` folder.
3. Run the following commands (replace `YOUR-USERNAME` with your GitHub username):

```bash
git init
git add .
git commit -m "Create portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/my-portfolio.git
git push -u origin main
```

If Git asks you to authenticate, complete the sign-in flow in your browser or use GitHub CLI. Do not share your password or access token.

## Enable GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. After publishing completes, your site should be available at `https://YOUR-USERNAME.github.io/my-portfolio/`.

GitHub Pages may take a few minutes to publish after the first setup.
